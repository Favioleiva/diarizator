# Controlled demonstration audio

`The_Measure_of_a_Good_Life.mp3` is a **controlled two-character dialogue
performed in one continuous take by one consenting speaker**. The performer
uses two contrasting vocal characters so the public pipeline can demonstrate
anonymous speaker-label separation without publishing a private conversation.

It is not a recording of two biologically distinct speakers. It is not a
general benchmark and has no reviewed reference RTTM, so it must not be used to
claim DER, JER, or general diarization accuracy.

The same interface used for arbitrary user uploads processes this demo. Demo
mode defaults to exact count 2 and records that count as oracle information;
estimated mode remains available.

See `demo_manifest.json` for technical metadata, `AUDIO_LICENSE.md` for its
separate CC BY 4.0 terms, and `TRANSCRIPT.md` for transcript-review status.
